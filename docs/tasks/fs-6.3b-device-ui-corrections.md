## Implementation

The existing WEB mobile cutoff is CSS width below 640px. This selects speed 0.1× and reach 5.0×; tablet/desktop keep 0.2× and 6.0×. A wide phone landscape viewport therefore follows the existing wide layout. Domain data owns those values; the existing composition root observes media changes through its DOM adapter and releases that listener with the scene. The controller updates only untouched speed/reach values, preserving custom slider choices and Pause. The customization Reset restores the current viewport defaults; no-argument scene reset retains its existing seeded-reset behavior. Explicit fixture configurations and generic particle consumers retain their defaults.

Tree rows use the existing desktop 24px label/36px icon/24px arrow metrics at all widths, including normal minimum row height and indent. Compact header navigation keeps its original responsive sizing. Contact's submit/retry control uses the existing secondary Button; the accepted-state Send another message action and delivery logic are unchanged. The skip link and its CSS are removed; existing first-focus, introduction, no-JS, main-target and route-recovery contracts have regression checks.
