## Inspection and decisions

1. The category rail preserves 8px of focus-ring padding, while ordinary button gaps are 12px. Its first gap to the menu was only the padding. Offset the rail by gap minus padding in both directions, and subtract that offset from the scroll budget. Keep every native button target, artwork size, trigger position and focus ring unchanged.
2. Only the desktop heading had enough left padding to avoid Close. The rest of the details column could start beneath Close; on wide screens the centered column moved away from the viewport-fixed Close. Give the entire column a minimum start coordinate that reserves Close, then position Close relative to that same coordinate. Its vertical alignment with Menu and the existing scroll-clearance rule remain intact. Mobile positioning is preserved.
3. Before hydration, `PortfolioNavigation` rendered the full fallback tree, then replaced it after its readiness effect. The first correction used a collapsed native Navigation disclosure. Dimi subsequently confirmed that its text and browser triangle still flashed. The final disclosure uses **the same hex artwork, dimensions, paint and launcher coordinates as the enhanced Menu**. Its accessible name is Navigation; it has no visible caption or native marker. Opening it exposes the existing ordinary-link tree in a scrollable native disclosure beside the trigger. It works with delayed/absent JavaScript; failed dialog opening still renders it **open**. No startup timer, browser script, theme-bootstrap change or new modal owner is added.

The native disclosure's `open` attribute can legitimately change before React starts. `suppressHydrationWarning` is scoped to that one element to allow the browser-owned state; no console errors are filtered or globally suppressed. The delayed-load regression opens it before hydration and asserts no page/console errors through enhancement and reload.

The no-JavaScript presentation now requires opening the native Navigation disclosure. Tests exercise that real interaction before checking the unchanged destinations, legal links, responsive layout and accessibility. This is an intentional presentation adjustment; it does not hide links permanently or replace them with an inert JavaScript-only trigger.
